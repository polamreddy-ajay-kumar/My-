# Ajay Kumar - Storyfolio

## Preview
Open folder in VS Code, install "Live Server", right-click index.html, Open with Live Server.

## Fill in
1. Put photos in assets/: me-cutout.png (background removed), og-image.jpg (1200x630).
2. Edit js/content.js: email, GitHub, LinkedIn, stats, project links.

## Deploy on GitHub Pages
index.html must be at the ROOT of the repo (not inside a sub-folder).
Settings -> Pages -> Source: Deploy from a branch -> main / (root) -> Save.
Site opens at https://<username>.github.io/<repo-name>/
